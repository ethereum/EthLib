# Hand conversions that the package still makes around the native calls.
#
# An entry is a file, a function and a rule.
#
# It covers every conversion of that rule in that function.
# A nested function is named after its outer function, as `outer.inner`.
# Code outside every function is named `<module>`.
# Each entry goes once its export takes and returns typed values.
# An entry that matches no conversion fails the check.
# A new entry is an exception that a maintainer approves, and the diff shows it.
# A pull request that moves a conversion to another function renames its entry.
