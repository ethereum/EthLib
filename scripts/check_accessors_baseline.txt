#
# `xs[i]!`, `get!`, `set!`, `panic` and the like return a default value, or change nothing,

#

# `lake exe check-accessors` fails on a site not listed here.
# It also fails on an entry that no longer matches.
# So this file is always the exact list.
# Remove or lower an entry in the pull request that removes its sites.
# Never add one: a new site is fixed, not listed.
