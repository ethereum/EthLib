# Vendored DAO Fork specification

`eip-779.md.txt` is EIP-779, the meta EIP of the DAO Fork.
It lists the 116 accounts whose ether the fork moves, and the recovery contract that receives it.
It is the file `EIPS/eip-779.md` below, renamed so that the Markdown checks of the repository skip it.

- Repository: [`ethereum/EIPs`](https://github.com/ethereum/EIPs).
- Commit: `46976b2a9bf99f727fb87dc8c809e3a3cdc6b445`.
- File: `EIPS/eip-779.md`.
- Licence: CC0-1.0, as the file states.

The file is copied byte for byte, and `SHA256SUMS` pins it.
To check the pin, run this from the directory:

```text
sha256sum -c SHA256SUMS
```
